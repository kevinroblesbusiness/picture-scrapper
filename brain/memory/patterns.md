# Pattern Recognition — What Combinations Work

## Approved Combos (8/10+)
| Character | Setting | Outfit | Makeup | Pose | Rating |
|-----------|---------|--------|--------|------|--------|
| Leah | Late night gas station | Charcoal halter crop + black leather mini | Smoky liner, glossy nude lip, sharp contour | Leaning on car hood, palms back, legs crossed | 8/10 |
| Catalina | Cobblestone European alley, golden hour | Ivory off-shoulder ruched mini dress | Ballet core — pink flush, cloud lip, dewy skin | Walking toward camera, looking off to side | 8/10 |

## Patterns I've Noticed
- Moody night lighting + fitted dark outfit + smoldering gaze = strong Leah results
- Warm golden hour + soft romantic setting + feminine silhouette = strong Catalina results
- Settings with mixed lighting (neon + fluorescent, or golden + string lights) outperform flat single-source lighting
- Specificity in fabric description (satin, ribbed, vinyl, ruched) helps AI generate correctly
- Spatial clarity in setting description is critical — vague indoor/outdoor mix confuses generation
