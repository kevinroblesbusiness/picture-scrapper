# Universal Rules — Apply to Every Single Prompt

## Output Format
- Always wrap the final prompt in a code block so it's one-tap copy on mobile

- Full body shot — always, no exceptions
- Full face of makeup — always specified
- White nail polish — always on toes
- All five toes visible on each foot — say exactly "all five toes visible on each foot"
- Footwear: indoors/home → barefoot | outdoors/dressed up → strappy heels, heeled sandals, or trendy sandals
- "The photo appears to be captured with a smartphone" — include in every prompt
- HEX VALUES — always carry over from raw prompt or generate a matching palette
- Only save prompts the user explicitly approves — never log on assumption
- Target age group: 18-25 Gen Z
- Sex appeal appropriate for Instagram fashion/nail polish marketing
