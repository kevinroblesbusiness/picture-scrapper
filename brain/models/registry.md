# Model Registry

## How to Add a New Model
Copy the template below, fill in details, save as brain/models/[name].md
Create matching tracker: brain/memory/tracker_[name].md
Add to daily_schedule.md

---

## Template
```
# [Model Name]
**Description:** [physical description for prompt]
**Vibe:** [aesthetic/personality in 1 line]
**Color palette:** [signature colors]
**Hard rules:** [any NO rules]
**Works:** [what's been proven]
**Flopped:** [what failed]
**Approved:** [list approved files]
```
